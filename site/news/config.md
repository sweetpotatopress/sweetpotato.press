no longer any need to create a config file manually or input the data manually, its much simpler and can be done entirely within astro by searching for a city, opening the config menu by pressing c, pressing tab to autofill, and enter to save. the file will be created automatically. i also included the option to toggle aspects on or off, for people that prefer a cleaner look.   

more detailed explanation is in [docs](https://sweetpotato.press/docs.html#how-to-set-default-location)

[check out astro here](https://codeberg.org/yamlynn/astro)
